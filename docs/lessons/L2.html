语法和句型

A 离 B ＋ 很远 / 很近

说两个地方远不远：A 离 B 很远 / 很近 / 不远

我家离lí学校很近jìn。

机场jīchǎng离lí我家很远yuǎn。

地铁dìtiě站离lí这儿不远yuǎn，走路zǒulù五分钟。

你家离学校远吗？我家离学校很近 / 很远。
商场离你家远吗？商场离我家不远。

已经……了 ／ 快要……了

已经……了 = already　　快要……了 = about to

我已经yǐjīng到车站chēzhàn了。

公交车gōngjiāochē快要kuàiyào来了。

八点了，我们快要kuàiyào上课了！

你吃饭了吗？（已经）我已经吃饭了。
电影几点开始？（快要）电影快要开始了。

课文：阿依达怎么去学校？

先不看拼音读一遍。不认识的词点一下看拼音，点 🔊 听这一句。

小明
阿依达，你每天怎么去学校？
阿依达
我家离lí学校很近jìn，我经常jīngcháng走路zǒulù去，有时yǒushí也坐公交车gōngjiāochē。
小明
我家离lí学校很远yuǎn，我每天坐地铁dìtiě，路上lùshang要四十分钟。
阿依达
你每天几点出门chūmén？
小明
七点就出门chūmén了。你看，已经yǐjīng八点了，我们快要kuàiyào上课了！
阿依达
没关系，老师还没来呢。
阿依达怎么去学校？走路，有时坐公交车。
小明家离学校远吗？很远。
小明每天几点出门？七点。
