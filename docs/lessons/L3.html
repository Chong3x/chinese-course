语法和句型

动词 ＋ 过

V ＋ 过 = have done (before)　　没 ＋ V ＋ 过 = have never done

我去过guo中国。

我踢tī过guo足球zúqiú，但是没打dǎ过guo篮球lánqiú。

你看过guo这个电影吗？

你去过阿拉木图吗？我去过 / 没去过阿拉木图。
你游过泳吗？我游过泳。/ 我没游过泳。

动词 ＋ 得 ＋ 怎么样

跑得很快、跳得很好　　有宾语：跳舞 ＋ 跳得很好

她跑得de很快。

他跳舞tiàowǔ跳得de很好。

你画huà得de很不错！

她跑得怎么样？（很快）她跑得很快。
他踢足球踢得怎么样？（很好）他踢足球踢得很好。

课文：你有什么爱好？

先不看拼音读一遍。不认识的词点一下看拼音，点 🔊 听这一句。

小明
阿依达，你有什么爱好àihào？
阿依达
我的爱好àihào是跳舞tiàowǔ和画huà画。我五岁就开始kāishǐ跳舞tiàowǔ了。
小明
你跳得de怎么样？
阿依达
跳得de还不错。你呢？你喜欢什么运动yùndòng？
小明
我喜欢踢tī足球zúqiú，也喜欢打dǎ篮球lánqiú。你踢tī过guo足球zúqiú吗？
阿依达
没踢tī过guo。我觉得足球zúqiú有点儿没意思méi yìsi。我喜欢游泳yóuyǒng，游泳yóuyǒng的时候身体shēntǐ很舒服shūfu。
小明
那星期六我们一起yìqǐ去游泳yóuyǒng吧！
阿依达
好啊！我希望xīwàng星期六天气很好。
阿依达的爱好是什么？跳舞和画画。
她几岁开始跳舞？五岁。
他们星期六去做什么？一起去游泳。
